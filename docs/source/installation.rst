Installation
============

FluxFEM supports Python 3.11-3.13 and depends on JAX 0.8.2.

Quick install (pip)
-------------------

.. code-block:: bash

   pip install fluxfem

Poetry
------

.. code-block:: bash

   poetry add fluxfem

From source
----------------------

.. code-block:: bash

   git clone https://github.com/kevin-tofu/fluxfem.git
   cd fluxfem
   pip install -e .
