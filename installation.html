Installation#

FluxFEM supports Python 3.11-3.13 (inclusive) and depends on JAX >= 0.8.2. The base install includes CPU JAX. Use the CUDA extra if you need GPU support.

JAX (CPU)#

pip install -U "jax[cpu]"

JAX (GPU)#

Install the CUDA-enabled JAX build that matches your CUDA toolkit. See the official JAX install guide for the latest wheels:

https://jax.readthedocs.io/en/latest/installation.html

Example (CUDA 12):

pip install -U "jax[cuda12]" -f https://storage.googleapis.com/jax-releases/jax_cuda_releases.html

Quick install (pip)#

pip install fluxfem
pip install "fluxfem[cuda12]" -f https://storage.googleapis.com/jax-releases/jax_cuda_releases.html

Poetry#

poetry add fluxfem
poetry add fluxfem[cuda12]

If you need a specific CUDA wheel, you can install JAX inside the Poetry env:

poetry run pip install -U "jax[cuda12]" -f https://storage.googleapis.com/jax-releases/jax_cuda_releases.html

PETSc (optional)#

Optional PETSc-based solvers are available via petsc4py. Enable with the petsc extra:

pip install "fluxfem[petsc]"
poetry add fluxfem --extras "petsc"

If you build or link against a custom PETSc installation, set PETSC_DIR (and PETSC_ARCH if applicable) so petsc4py can locate the libraries:

export PETSC_DIR=/path/to/petsc
export PETSC_ARCH=arch-linux-c-opt  # optional

Note: match the petsc4py version to your PETSc installation. FluxFEM currently pins petsc4py==3.24.4 in extras, so use a compatible PETSc build or override the version to fit your environment.

For source checkouts with a custom PETSc build, prefer installing the normal Poetry environment first and then building petsc4py against that PETSc:

export PETSC_DIR=/path/to/petsc-3.24.4
export PETSC_ARCH=arch-linux-c-opt
scripts/install_petsc4py

The script uses PETSC4PY_VERSION=3.24.4 by default and verifies that petsc4py can import PETSc. PETSc remains optional; if it cannot be imported, PETSc-specific tests are skipped by petsc_is_available().

GPU note: this repo currently tests CUDA via the cuda12 extra only. Other CUDA versions are not covered by CI and may require manual JAX installation.

From source#

git clone https://github.com/kevin-tofu/fluxfem.git
cd fluxfem
pip install -e .
